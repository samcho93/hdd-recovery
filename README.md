# HDD Recovery

파일시스템이 깨져 탐색기에서 열리지 않는 디스크의 데이터를 복구하고, 파일시스템 구조를 되살리거나 새로 만드는 Windows용 Electron 프로그램입니다.

## 할 수 있는 일

| 영역 | 기능 |
| --- | --- |
| 데이터 복구 | NTFS, FAT12/16/32, exFAT 파일 목록과 삭제 파일 복구. 압축, 희소, 조각난 NTFS 파일 지원 |
| 손실 볼륨 찾기 | 파티션 테이블, 부트 섹터, 백업 부트 섹터, `$MFT` 역산으로 사라진 볼륨 탐지 |
| 서명 스캔 | 파일시스템 없이 JPEG, PNG, GIF, BMP, PDF, ZIP/Office, HWP/DOC, MP4/MOV, AVI/WAV, SQLite, 7z 탐지 |
| 구조 복원 | MBR/GPT 재생성, GPT 기본↔백업 복원, NTFS 부트 섹터 복원 및 `$MFT` 기반 재생성, FAT32/exFAT 부트 복원, FAT 사본 복원 |
| 디스크 관리 | 빠른/전체 포맷, 파티션 생성·삭제·크기 변경·분할·통합, 디스크 초기화, 드라이브 문자·이름 변경, 파일시스템 검사, 32GB 초과 FAT32 포맷 |
| 이미징 | 디스크를 파일로 복제하고 읽지 못한 섹터 위치를 기록. 만든 이미지에서 바로 복구 가능 |
| 상태 확인 | 디스크 상태와 온도, 사용 시간, 읽기·쓰기 오류(SMART) |

## 데이터를 잃지 않으려면

1. Windows가 띄우는 "포맷하시겠습니까?" 또는 "디스크 초기화" 제안을 수락하지 마세요.
2. 소리가 나거나 오류가 많은 디스크는 **이미지** 탭에서 복제본부터 만들고, 복제본에서 복구하세요.
3. 복구한 파일은 다른 디스크에 저장하세요. 같은 디스크로는 저장할 수 없게 막아 두었습니다.
4. **구조 복원**보다 **파일 복구**를 먼저 하세요.

## 안전 장치

- 스캔, 진단, 복구, 이미징은 대상 디스크를 읽기 전용으로 엽니다.
- Windows 부팅 디스크, 시스템 디스크, 페이지 파일이 있는 디스크의 변경 작업은 차단합니다.
- 지우거나 구조를 바꾸는 작업은 `DISK n` 문구를 직접 입력해야 실행됩니다.
- 쓰기 직전에 화면의 디스크와 실제 디스크가 같은지(모델, 일련번호, 크기) 다시 확인합니다.
- 구조 복원은 덮어쓸 영역의 원본을 저널에 저장하고, 쓴 뒤 다시 읽어 검증하며, 나중에 되돌릴 수 있습니다.
- 파티션 통합 시 파일 보존을 선택하면 복사가 실패할 경우 아무것도 지우지 않습니다.

## 알려진 한계

- Windows는 FAT/exFAT 폴더를 삭제할 때 폴더 목록을 0으로 지웁니다. 그런 폴더 안의 파일 이름은 복구할 수 없고, 내용은 서명 스캔으로 찾아야 합니다.
- FAT/exFAT의 삭제 파일은 연속 저장을 가정해 복구하므로 조각나 있었다면 내용이 깨질 수 있습니다. 앱이 경고로 표시합니다.
- 서명 스캔 결과에는 원래 파일 이름과 폴더 구조가 없고, 조각난 파일은 온전하지 않을 수 있습니다.
- BitLocker, ReFS, ext, HFS+는 식별만 합니다. EFS 암호화 파일은 암호화된 상태로 저장됩니다.
- NTFS 대체 데이터 스트림은 복구하지 않습니다.
- `$MFT`로 다시 만든 NTFS 부트 섹터에는 부트 코드가 없어 데이터 디스크에 적합합니다. 부팅 디스크라면 Windows 복구 도구가 추가로 필요합니다.
- 기계적으로 고장 난 디스크(인식 불가, 헤드 손상)는 소프트웨어로 복구할 수 없습니다. 중요한 데이터라면 전문 업체에 문의하세요.
- 설치 파일에 코드 서명이 없어 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다.

## 개발

```bash
npm install
```

```bash
npm start
```

디스크에 직접 접근하려면 관리자 권한이 필요합니다. 일반 권한으로 실행하면 앱에 다시 실행 버튼이 나타납니다.

| 명령 | 설명 |
| --- | --- |
| `npm test` | 엔진 단위 테스트. Windows가 실제로 포맷한 이미지를 손상시켜 복구 결과의 해시를 확인 |
| `npm run test:e2e` | Electron 앱을 띄워 이미지 대상으로 복구·복원 흐름 조작 |
| `npm run test:integration` | 관리자 권한 필요. 임시 VHD를 연결해 포맷·분할·통합과 복원 후 Windows 재마운트, chkdsk 통과를 확인 |
| `npm run fixtures` | 관리자 권한 필요. 테스트용 디스크 이미지 재생성 |
| `npm run dist` | `release/`에 설치 파일과 포터블 실행 파일 생성 |

### 구조

```
src/engine/    디스크 형식 처리(Electron 무관, 메모리/파일/물리 디스크 공통)
  device       불량 섹터를 건너뛰는 블록 장치 추상화
  partition    MBR/GPT 읽기·쓰기
  ntfs fat exfat   파일시스템 파서와 파일 추출
  scanner      손실 볼륨 탐지
  carver       서명 기반 복구
  repair       진단, 복원 계획, 저널과 되돌리기
  mkfat32      FAT32 포맷터
src/main/      Electron 메인 프로세스, 작업 관리, Windows 저장소 명령
src/renderer/  React 화면
```
